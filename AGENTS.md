# Repository work

For report generation, read `AI_USAGE.md` and one matching example; do not audit the whole engine. Follow the user's current content/recipient/language requirements.

For engine changes, preserve approved cover variants, semantic input, independent page artifacts and final rendered verification. Run relevant regression tests and inspect affected PNGs. Never commit private client reports, credentials, output caches or generated build bundles. Runtime/dependency/font changes must invalidate reuse.

Use local rendering/tests. No GitHub Actions are required. Keep the public chat instructions concise and consistent with the actual CLI.
